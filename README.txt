SON NGUYEN E-PORTFOLIO

FILES
- index.html        About / landing page
- research.html     Research page
- coursework.html   Coursework page
- resume.html       CV/Resume page
- styles.css        Site styling
- assets/           Images + downloadable resume

QUICK PREVIEW
1. Unzip this folder.
2. Double-click index.html.
3. Use the navigation tabs to test every page.

RECOMMENDED FREE PUBLISHING — GITHUB PAGES
1. Create or sign in to GitHub.
2. Create a new PUBLIC repository, e.g. son-nguyen-eportfolio.
3. Upload every file/folder from this package, keeping the assets folder intact.
4. Open repository Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. GitHub will show your public site URL after deployment.
8. Open the URL in an incognito/private window to confirm it is publicly accessible.
9. Submit that URL to the USP Canvas assignment.

ALTERNATIVE
You can also publish the folder through Netlify Drop.

BEFORE SUBMITTING
- Click About, Research, Coursework, and CV/Resume.
- Check the headshot appears.
- Check both research images appear.
- Click Download Resume (PDF).
- Check the UF email and LinkedIn links.
- Test on your phone.
- Confirm the site is public.
